## About us

Instrumental Identity (IID) provides assessments, software, implementation services, and consulting for IAM programs and platforms, including SailPoint (IIQ/ISC), Evolveum midPoint, Microsoft Entra ID, and Internet2 Grouper. Identity is all we do!

Our senior architects each have 10+ years experience in the IAM field. We're an [Internet2 InCommon Catalyst partner](https://incommon.org/community/catalyst/).

You may know us as IdentityWorksLLC. We rebranded in 2023, but we're still the same company with the same people.

## Open-source tools

GitHub is now the official home for Instrumental ID's open-source software, including our SailPoint IIQ plugins, iiq-common-public, and our ISC work.
